## Definition of ready

A story is ready only when it has:

- Unique ID and phase
- Canonical persona
- Business outcome and acceptance criteria
- Data and security classification
- License and authentication implications
- UX and accessibility acceptance criteria
- Dependencies and integration assumptions
- Estimate, owner, and validation approach
